# 출처와 참고 (CREDITS)

Branding guide 스킬은 AI로다했서누가 만들었다. 문장과 스크립트는 직접 새로 썼고, 아래 자료에서는 **생각의 틀(구성 방식)**만 참고했다. 원문 문장이나 코드를 그대로 옮기지 않았다.
이 스킬은 Anthropic이나 아래 제작자가 만들거나 보증한 것이 아니다.

## 쓴 개념과 기준

| 개념 | 처음 만든 사람·곳 |
|---|---|
| 골든 서클 (Why → How → What) | 사이먼 시넥(Simon Sinek), *Start With Why* (2009) |
| 4P (제품·가격·유통·홍보) | E. 제롬 매카시(E. Jerome McCarthy), *Basic Marketing* (1960) |
| 글자 대비 4.5:1 · 3:1 | W3C 웹 콘텐츠 접근성 지침(WCAG) 2.x |
| 60·30·10 색 비율 | 실내·그래픽 디자인에서 널리 쓰는 경험칙 (특정 출처 없음) |
| 상표 검색 안내 | 특허청 특허정보검색서비스 키프리스(KIPRIS, kipris.or.kr) |
