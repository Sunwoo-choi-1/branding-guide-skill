# 매장 로고

## 로고가 이미 있을 때
- 로고는 고치지 않는다. 손님이 이미 알아보는 얼굴이다.
- 로고에서 색을 뽑아 브랜드 컬러의 메인으로 쓴다.
- 쓰는 규칙을 정리한다: 주변 여백(로고 높이의 1/4 이상), 밝은 바탕·어두운 바탕용, 최소 크기, 하지 말 것(늘리기, 눕히기, 그림자, 색 바꾸기).
- 로고 파일이 흐린 사진뿐이면 "원본 파일(AI, PDF, PNG)이 있으면 그걸 쓰세요. 없으면 시안 3개로 깔끔하게 다시 그려 드릴 수 있어요"라고 안내한다.

## 로고가 없을 때: 시안 3개
| 시안 | 생김새 | 어울리는 가게 |
|---|---|---|
| 1 워드마크 | 가게 이름 글자 + 메인색 밑줄 + 작은 영문 | 이름이 짧고 또렷한 가게 |
| 2 사각 배지 | 메인색 사각형 안에 이름 | 포장 스티커·도장·SNS 프로필 |
| 3 이니셜 심볼 + 이름 | 첫 글자 사각 심볼 + 이름 | 간판, 가로로 긴 자리 |

만드는 법:
```
python scripts/logo_drafts.py --name "가게 이름" --sub "영문 이름 또는 업종" \
  --main "#메인" --text "#글자" --bg "#배경" --accent "#강조" --out logo
```
`logo/preview.html`을 열어서(또는 아티팩트로) 사장님께 보여 준다. 코드 실행이 안 되면 같은 구성으로 SVG 코드를 직접 쓴다.

사장님이 고르면, 고른 시안을 기준으로 글자 간격·굵기·색을 한두 번 다듬는다. 일러스트(빵, 커피잔 같은 그림)를 넣고 싶어 하면 단순한 도형 몇 개로 그린 SVG를 만들고, 복잡한 그림은 디자이너나 이미지 생성 도구를 권한다.

## 꼭 같이 말할 것
- "시안이에요. 간판·포장·스토어에 쓰기 전에 **키프리스(KIPRIS, kipris.or.kr)**에서 비슷한 상표가 있는지 검색해 보세요."
- "인쇄할 때는 디자인 툴에서 글자를 외곽선(아웃라인)으로 바꿔 주세요. 안 그러면 다른 컴퓨터에서 글꼴이 바뀔 수 있어요."
- 다른 브랜드 로고를 따라 그려 달라는 부탁에는 응하지 않고, 분위기만 참고한 새 시안을 제안한다.

## 챗GPT에서 쓸 때
챗GPT 무료는 하루에 만들 수 있는 이미지 수가 적다. 이미지 생성을 한 번에 쓰도록 프롬프트를 이렇게 정리해 준다:
"{가게 이름} 로고. 한글 '{이름}' 글자가 또렷하게 보이는 단순한 워드마크. 색은 {메인 HEX}와 {글자 HEX}만. 배경 {배경 HEX}. 그림자·그라데이션·사진 없이 평평하게."
이미지 생성기는 한글 글자를 틀리게 쓸 때가 많다. 글자가 틀리면 글자 없이 심볼만 만들고, 이름은 디자인 툴에서 직접 넣으라고 안내한다.
