# 브랜드 컬러 정하는 법

## 순서
1. 로고가 있으면 로고 색이 메인이다. 사장님이 이미 손님에게 보여 온 색이라서 바꾸지 않는 게 낫다.
2. 로고가 없으면 상품·가게 사진에서 뽑는다. `scripts/palette.py`가 역할 후보를 주지만, 그대로 쓰지 말고 아래 기준으로 한 번 더 본다.
3. 사장님이 고른 분위기 단어(따뜻한, 깔끔한 등)와 맞는지 본다. 사진은 차가운 회색이 많아도 가게 분위기가 따뜻하면, 사진 속 따뜻한 색을 메인으로 올린다.
4. 5가지 역할로 정리하고 사장님께 보여 준다. 색 이름(예: "구운 빵 껍질 갈색")을 붙여 주면 사장님이 기억하기 쉽다.

## 5가지 역할
| 역할 | 기준 |
|---|---|
| 메인 | 가게를 떠올리면 생각나는 색. 너무 어둡거나(거의 검정) 너무 밝으면(거의 흰색) 메인으로 약하다 |
| 서브 | 메인과 같은 계열에서 밝기만 다른 색. 도형·구분선용 |
| 강조 | 메인과 색상이 다르고 눈에 띄는 색. 가격·할인·한 단어에만 쓴다 |
| 배경 | 아주 밝은 색. 흰색보다 메인 쪽으로 살짝 물든 색이 브랜드 느낌이 난다 |
| 글자 | 아주 어두운 색. 검정보다 메인 쪽으로 살짝 물든 색이 부드럽다 |

## 60 · 30 · 10
- 배경 60, 메인 30, 강조 10. 강조색이 늘어나면 강조가 안 된다.
- 카드뉴스 한 장에서 강조색은 한 군데만.

## 글자 대비
- 본문 글자와 배경: 4.5:1 이상.
- 큰 제목(약 24px 이상, 굵게): 3:1 이상.
- 부족하면 글자색을 더 어둡게 하거나 배경을 더 밝게 조정한 HEX를 제안한다. 원래 색을 버리지 말고 "조정한 색"으로 나란히 보여 준다.

## 코드 실행이 안 될 때
사진을 보고 눈으로 추정한다. HEX 옆에 "(추정)"을 달고, "디자인 툴(캔바·미리캔버스) 스포이드로 한 번 확인해 주세요"라고 안내한다.

## 결과 파일에 쓰는 법
9번 표에 HEX, 쓰는 곳, 대비 숫자를 적고, 카드뉴스에 쓰는 규칙을 한두 줄 붙인다. 이 표가 있으면 다음에 "우리 브랜드 컬러로 카드뉴스 만들어줘"가 바로 된다.
