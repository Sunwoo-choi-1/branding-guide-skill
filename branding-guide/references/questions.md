# 빈칸 다시 묻기: 질문 은행

첫 메시지(질문 5개)에서 비어 있는 칸만 골라서 묻는다. 한 번에 2~3개까지만 묻고, 질문마다 보기를 붙인다. 보기 끝에는 늘 "다른 거면 그냥 적어 주세요"를 붙인다.

## SNS 계정·퍼스널 브랜딩일 때
- 계정(또는 나)을 한 줄로 소개하면요? → "○○하는 사람" 꼴로
- 팔로워·고객이 나한테서 얻어 가는 건요? → 정보 / 재미 / 위로·공감 / 실력·결과
- 비슷한 계정·사람이 많은데, 나만 하는 건요? → 직접 해 본 것만 / 숫자로 보여 줌 / 말투·캐릭터 / 한 분야만 깊게
- 콘텐츠는 어떤 형식이 많아요? → 릴스·쇼츠 / 카드뉴스 / 긴 글 / 라이브
- 얼굴이 나오나요? → 나와요 / 손·목소리만 / 안 나와요 (프로필·로고 방향이 달라져요)
- 이 계정으로 결국 뭘 하고 싶어요? → 수익(강의·상품) / 본업 홍보 / 협찬 / 아직 모름

## 가게 기본
- 주로 어디서 파세요? → 매장 / 네이버 스마트스토어 / 인스타 DM / 배달앱 / 쿠팡 / 기타
- 가격대는 주변 가게랑 비교하면 어느 쪽이에요? → 더 싸요 / 비슷해요 / 조금 비싸요 / 꽤 비싸요
- 가게 연 지 얼마나 됐어요? (모르면 넘어가도 돼요)

## 손님이 고르는 이유 (골든 서클 Why)
- 단골 손님이 제일 자주 하는 칭찬은요? → 맛·품질 / 친절·응대 / 가격 / 분위기 / 가까워서 / 믿을 수 있어서
- 손님이 우리를 처음 알게 되는 경로는요? → 지나가다 / 네이버 검색 / 인스타 / 지인 소개 / 배달앱
- 손님이 다른 데 갔다가 다시 돌아온 적 있어요? 그때 뭐라고 했어요?
- 리뷰 중에 제일 기억에 남는 한 줄을 붙여 주세요.

## 셀링포인트 (4P)
- 제품: 같은 걸 파는 다른 가게랑 **만드는 방법**에서 뭐가 달라요? → 재료 / 시간·공정 / 양 / 메뉴 구성 / 직접 만든 것
- 가격: 그 가격인 이유가 있어요? → 좋은 재료 / 양이 많음 / 손이 많이 감 / 동네 단골 가격
- 유통: 손님이 받는 방법은요? → 매장 / 픽업 / 택배 / 배달 / 정기 배송
- 홍보: 지금 손님을 부르는 데 쓰는 건요? → 네이버 플레이스 / 인스타 / 당근 / 전단 / 거의 안 함

## 암묵지 (머릿속에만 있는 것)
- 처음 이 일을 시작한 이유가 있어요?
- 절대 타협 안 하는 거 하나만 꼽으면요?
- 손님한테 설명할 때 자주 하는 말이 있어요? ("이건 꼭 ~해서 드세요" 같은 거)
- 손님은 모르는데 사장님은 매일 하는 수고는요?

## 브랜드 페르소나
- 우리 가게가 사람이라면 어떤 사람이에요? → 동네 단골 챙기는 이웃 / 꼼꼼한 장인 / 유쾌한 친구 / 차분한 전문가
- 손님이 우리 가게를 나설 때 어떤 기분이면 좋겠어요?
- "우리 가게는 이런 느낌은 아니에요" 하는 게 있어요? (예: 너무 고급스러운 척, 너무 가벼운 척)

## 말투
- 평소 손님을 뭐라고 불러요? → 고객님 / 손님 / 이웃님 / 따로 안 불러요
- 말 끝은 어떤 쪽이에요? → ~요체 / ~습니다체 / 반말 섞어서
- 이모지 쓰세요? → 많이 / 가끔 / 안 써요
- 절대 안 쓰는 말이 있어요?
- 써 놓은 글이 하나도 없으면: 아래 세 문장 중 제일 우리 가게 같은 걸 골라 주세요.
  - A. "오늘 소금빵 다 나갔어요! 내일 아침 8시에 또 구워요."
  - B. "금일 소금빵은 조기 품절되었습니다. 내일 오전 8시에 다시 준비하겠습니다."
  - C. "소금빵 완판🥐 내일 8시에 만나요~"
  (업종에 맞게 예문을 바꿔서 쓴다)

## 컬러·로고
- 로고가 있어요? → 있어요(사진 올리기) / 간판만 있어요(간판 사진) / 없어요
- 꼭 쓰고 싶은 색이나 절대 안 쓰는 색이 있어요?
- 로고에 넣고 싶은 글자는요? → 한글 이름 / 영문 이름 / 둘 다 / 이니셜만
- 가게 분위기를 세 단어로 고르면? → 따뜻한 / 깔끔한 / 귀여운 / 고급스러운 / 자연스러운 / 힙한 / 정겨운

## 마케팅
- 이번 달에 제일 늘리고 싶은 건요? → 새 손님 / 재방문 / 온라인 주문 / 객단가
- 일주일에 마케팅에 쓸 수 있는 시간은요? → 30분 / 1시간 / 2~3시간
- 지금 쓰는 채널 중 제일 반응이 좋은 곳은요?
